# Glossary map

One glossary per context. Read the ones relevant to the area you're working in.

| Context | Path               | Covers                                                          |
| ------- | ------------------ | --------------------------------------------------------------- |
| desktop | `apps/desktop/`    | Electron shell: windows, app lifecycle, the bundled Next server |
| web     | `apps/web/`        | The app's UI: pages, components, client state                   |
| api     | `packages/api/`    | The HTTP contract: endpoints and schemas                        |
| server  | `packages/server/` | Domain services and handlers behind the API                     |
